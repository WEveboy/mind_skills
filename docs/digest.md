# 四书的整体理解与任务地图

本项目把四本书变成一个有任务路由的技能。它们解决不同瓶颈：既有问题表述可能锁住选择，局部观察可能漏掉反馈，行动可能缺乏观测与修正，结论可能超出前提。组合顺序随任务改变，不把“创新—系统—控制—逻辑”规定成普遍必经流程。

## S1 水平思考

第1—2章区分产生路径与事后论证，并讨论创新困难；第3章关注主导观念；第4章通过图形拆分显示基本元素的选择会限制组合；第5—7章分别转移视角、暂缓逐步逻辑审查、利用偶然刺激；第8章以发明故事展示重新组合；第9—10章把方法扩展到日常并培养习惯。第11—13章把创造力训练落实到游戏、随机词；第14章提供62个训练；第15章给工具表；附录介绍六顶帽。

主线不是抛弃逻辑，而是别在尚未找到入口前就只沿一个框架筛掉想法。方法进入M1，原例仅作为机制说明。第4章图形、62个游戏、工具表及附录未逐例复核，不复刻游戏全集，不声称教学效果经实验验证。

## S2 系统之美

第1章从元素、连接和目标进入存流及反馈；第2章用单存量、双存量系统显示结构生成不同动态行为。第3章讨论适应力、自组织、层次；第4章解释非线性、边界、限制因素、延迟、有限理性导致的意外。第5章给反复失效的结构，例如目标侵蚀、转嫁负担；第6章从参数到信息、规则、目标与范式讨论改变系统的位置；第7章强调学习、反馈、整体责任与时间范围。

已读重点支持M2和M3：存量的变化由净流量决定，反馈对时间和边界敏感。陷阱和杠杆用于提出结构假说，不能依据一个症状自动分类。本次第2章各数学模型、第3章层次细节、第5章全部陷阱、第7章全文未完成逐页审读，保留补读任务，不虚报整书验证。

## S3 控制论与科学方法论

第1章从可能性空间进入选择、控制能力和反馈；第2章把信息理解为可能性空间的变化并讨论传输、过滤、存储及组织；第3章从因果网络建立相对孤立系统，再讨论稳态、振荡、超稳定、自组织和演化；第4章用稳定机制、突变和分岔区分渐变与飞跃；第5章将认识表达为可观察与可控制变量之间的反馈，讨论模型、观测限制、反馈过度和判定条件。

M3抽取控制目标、传感与动作，M4抽取可观测/可控边界与模型辨别。第2章通道容量等数学细节未核验，第3章超稳定及第4章突变理论只作参考，不推导组织命运或灾变阈值。第5章的认识论启发不当成科学真理的充分判据。

## S4 简单的逻辑学

第1章要求注意现实、确认事实并澄清语言；第2章建立基本原理、因果探寻和命题/定义；第3章分开前提与结论，讨论全称/特称、条件、三段论、演绎、归纳及类比；第4章讨论阻碍推理的态度；第5章逐类检查错误推理与无关说服。

M5保留可操作规则，而不按28种谬误给人贴标签。对推理结构给反模型，对事实给查证需求，对价值给显式标准。书中个别表述需收窄；纠正记录在技能sources.md。推荐序的社会判断没有被当成作者逻辑定理。

## 各章档案的共同条件

创新依赖目标与约束；存流模型依赖同口径与时间边界；控制依赖观测、动作能力及响应；黑箱辨别依赖不同假说能给不同预测；逻辑保真依赖前提真实和形式有效。每项详细机制、输入、步骤、例/反例、自由度与完成标准见五张能力卡。未读与未证范围见reading-coverage.json及coverage-audit.md。
