# M4 黑箱辨别

- R：S3 §5.1 PDF 184—187、§5.3 PDF 195—196、§5.7 PDF 210—211；§3.2 PDF 95—96。
- I：可观测变量和可控制变量限定我们能够区分什么。不同内部模型可能产生同样输出；反复拟合已有输出不能自动确定真实机制。
- A1 原例：S3 PDF 186—187，以外部输入输出研究手表或遗传因子，并区分打开内部结构与黑箱建模。故事中的科学史细节未独立考据。
- A2：多个解释都能解释结果、试验反复却不进展；不适合凭一次观察确定隐藏人格或真实动机。

## E 执行契约

1. 写观察到什么、能改变什么、不能看到什么。观察与动作分列；不要把无法操控的变量说成实验处理。
2. 建至少两个可竞争假说，说明相同条件下各自预测什么；加入测量或口径变化这一解释（若相关）。
3. 选择预测会分叉的输入或新增观察。优先低代价、可逆、符合权限的比较；能控制时保持其他关键条件相同，不能控制时明确混杂。
4. 事先写“若观察 X，支持/削弱哪个假说”；若两者预测相同，则这个试验不能区分它们，改变量、测量尺度或承认暂不可辨。
5. 记录过程、干扰与结果，区别反驳某个模型、未检出效果与证明另一模型正确。对新数据更新模型，保留旧预测和失败条件。

完成：每个建议观察能说明如何改写判断，或明确现有观测下无法识别。

- B：干预可能改变黑箱结构本身；样本小、外部环境变动和遗漏变量限制迁移。不得将更小的拟合误差直接等同更接近真理；本包不提供普适科学真理判定算法。
