## E 执行契约

1. 忠实转述结论 C、显式前提 P 和必要隐含前提 H。H 标为补充假设，请勿冒充对方原话。
2. 定义关键术语、量词、时间、比较基线；分开“事实如何”和“应该怎样”。事实前提不能自行产生价值结论。
3. 先评形式，再评证据。P→Q 与 P 可推出 Q；P→Q 与 ¬Q 可推出 ¬P；P→Q 与 Q 不能推出 P；P→Q 与 ¬P 不能推出 ¬Q。
4. 对无效形式，给前提全真而结论假的赋值或具体情境。结论可能碰巧真，所以应写“此论证不足以证明”，不能自动写“结论假”。
5. 核查量词：部分到全部需要额外证据；全称不自动承诺对象存在；“不是全部”与“全部不是”不同。“或”须确认是兼容或还是排他或。
6. 对归纳、类比和因果推断，检查样本、关键相关相似点、遗漏条件和竞争解释；不要求它们达到演绎必然性，也不从先后直接断定因果。
7. 谬误诊断指出具体推理位置、为何不支持结论，以及保留合理内容的改写。专家意见可作有限证据，但需核对领域、依据及不确定性。不要给人贴非理性标签或推测恶意。

输出：结论 → 前提及证据状态 → 形式判断 → 反例/缺口 → 最小修复。缺原论证时请求原文，不凭标题判定。
