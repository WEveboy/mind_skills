# mind_skill

将《水平思考》《系统之美》《控制论与科学方法论》《简单的逻辑学》的选定方法综合为一个中文技能：重构问题、诊断系统、设计反馈、区分解释、审查论证。

版本0.1.0，研究试用。采用《文本蒸馏2.0》2.0.0流程，直接生成，不依赖仓颉编译器。完整阅读和评测范围见 [覆盖审计](docs/coverage-audit.md)，不要将它当成四书全文已验证的替代品。

## 使用

完整复制 `skills/mind_skill/` 到宿主支持的技能目录后按该宿主要求加载。也可在能读本地文件的Codex中明确指定路径：读取 `skills/mind_skill/SKILL.md` 并按其中路由处理任务。本次已做显式文件加载和模型演练；没有修改用户全局技能目录，自动发现未测。

调用示例：`使用 $mind_skill 分析：我们的团队增加检查后返工反而增加，怎样找原因并设计小试验？`

用户明确指定下划线名称，本包保留 `mind_skill`。捆绑的通用校验器仅接受连字符名称，因此其命名检查不通过；本项目验证其余结构并记录此例外。严格要求连字符的宿主需要用户自行选定兼容别名，不能据此承诺所有宿主可自动发现。

## 核验

在仓库根运行 `python tests/test_models.py` 检查有限计算规则，运行 `python scripts/validate_package.py` 检查引用、自包含和公开清单。两者仅需Python标准库。

原书、全文提取、页图及机器专用路径留在private目录并排除公开。公开的是原创压缩说明、条件化方法、合成例及来源定位。尚未选定开源许可证，不宣称原书或本项目可任意再分发。

维护时先改能力卡与来源记录，重跑相关演练和边界用例，再更新版本及清单；已发布快照不静默覆盖。参见 [方法阅读稿](docs/digest.md) 与 [评测](evaluation/report.md)。
